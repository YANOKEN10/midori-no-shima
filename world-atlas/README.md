# ガオン・ワールド全体図（v64）

実際の86マップと109接続を収録。全体図には65の町・道路・ダンジョン・交通施設を表示し、44の建物は各町の詳細欄にまとめています。

- 同じ接続番号を両端に表示。番号を押すとその道を強調。
- 出入口の方向を使った配置と配線。線は区間を共有せず、交差は接続を意味しません。
- 検索、主な町への移動、ドラッグ・ピンチ・キーボード矢印で操作。
- 選んだ場所から目的地までの最少接続数の道順を表示。開通条件の判定はしません。
- 各町の病院・ショップなどは室内画像付きで表示し、検索・道順にも対応。
- map.svg / map.png は保存用の全体図、thumbs/ は実マップの画像。

更新手順（リポジトリのルートで実行）:
1. ローカルゲームを5182で起動し `node tools/extractWorldAtlas.cjs`。
2. `node tools/buildWorldAtlas.cjs` でゲームから接続グラフを作成。
3. `node tools/improveWorldAtlasV64.cjs atlas-source.json` で番号付き配線・詳細画像を作成。
4. `node tools/exportWorldAtlasV64.cjs` で保存用PNGを書き出す（PlaywrightとEdgeが必要）。

船・列車なども含む実際の接続に基づきます。地理的な距離・縮尺は模式的です。共有室内の戻り先は入口の町ごとに保持しています。
