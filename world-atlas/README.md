# ガオン・ワールド全体図

全86マップを実描画から抽出し、共有室内を町ごとに展開した109カード・109接続を表示。画像と接続は2026-09-16時点。

- index.html: 拡大縮小、場所検索、接続の強調
- map.svg: 拡大用の全体図
- map.png: 保存用画像
- data.json: マップ配置・接続

接続はMAPSのwarps/travelLinksと船・列車・廃墟入口イベントから収集。@backは入ってきた町へ戻るため、室内を入口ごとに分けています。ストーリーによる一時的な帰還、敗北帰還は含めません。配置は出入口方向を基準とする模式図で、地理的な距離ではありません。

更新: ローカルサーバーを5182で起動し、リポジトリのルートで node tools/extractWorldAtlas.cjs → node tools/buildWorldAtlas.cjs。出力されたatlas-source.jsonは中間素材です。PNGはSVGをブラウザで6000px幅に描画して書き出しています。
