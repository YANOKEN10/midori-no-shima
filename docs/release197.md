# Release 197 — 読みやすい会話と道具名

- 小学1～5年の漢字にひらがなのふりがな、小学6年以上の漢字はひらがな表示。
- 会話・選択肢・道具一覧・道具説明を対応。難しい言葉・道具名に表示用の言い換えを追加。
- 採掘セットの表示を「たんけんセット」に統一。マップ工房の道具パレット・ショップ品ぞろえ・住人の贈り物も同じ表示名。
- セーブデータの道具キー・価格・効果は変更しない。英語表示は従来の翻訳を維持。
- 開発時に読み辞書を生成するため、ブラウザーに形態素解析器を追加しない。

検証: tools/verifyReading197.cjs — 全534道具、4077か所の漢字パーツ、表示名の重複なし、説明の幅、会話ページ送り、選択結果の旧ID保持、英語表示、ブラウザー例外なし。会話・道具画面のスクリーンショットも目視確認。

辞書・配当表・ライセンスは reading197-sources.md を参照。
