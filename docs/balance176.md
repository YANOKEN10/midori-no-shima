# 能力バランス v176

6能力の種族値を調整。ラテット740、ディーナ640、メロロン620。通常197体は最大688を600へ縮小する共通倍率600/688を使用。
各種の新合計に対して元の能力比率で比例配分し、最大剰余法で整数にする。各能力の理想値との差は1未満。能力の大小関係は逆転させない。
キラルだけは元の進化合計410→380が逆転しているため、共通倍率の358から330へ追加縮小。キラモル331を下回り、すべての進化の合計が上がる。
個体値・努力値・レベル・技・獲得努力値・捕獲率・進化条件は保持。能力計算はゲームと図鑑が同じSPECIESを参照する。
既存セーブは新旧の最大HPから残りHP率を1回だけ変換。手持ち・ボックス・預かり中の親子が対象。瀕死は0のまま、新規個体は移行済み印を付ける。
