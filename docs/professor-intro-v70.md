# Swiss professor introduction v70

New adventures show the existing Swiss professor sprite in a dedicated scene before name entry. The seven requested messages are presented in order, substituting the entered name. Appearance selection follows the name acknowledgement. The game is saved and the world entered only after the farewell. Cancelling either form returns to the title; continuing a local/cloud save bypasses the introduction.

Validation: browser test starts a fresh game through the title menu, advances all supplied dialogue, enters a name, confirms appearance, checks saved name and world entry, reloads and continues without replaying the introduction. Screenshots reviewed for professor placement, dialogue wrapping and name label. No browser errors.
