# 技ルールとわざじゅもん（192）

種族の基本アタックとマジックを比較。差20以上は高い側の攻撃分類のみ、差20未満は習得表の物理・特殊を同数にする。変化技と習得レベルは保持。既存ガオンは読込時と進化後に合わない攻撃技を更新し、残PPの割合を保持する。混合型の現在の技は奇数なら差1以内。思い出し・育て屋の特別技にも分類制約を適用。

全292技を「わざじゅもん：技名」として登録。専用バッグポケット。習得成功のみ1個消費。4技時は忘れる技を選択。習得済み・キャンセル・分類不一致は消費しない。マップ工房の拾えるアイテム・人物からの贈り物・ショップ商品に登録。

検証: node tools/verifyMoves192.cjs（300種・境界19/20・変化技保持・移行の再実行・全292アイテム）。node tools/verifyBrowser192.cjs（実メニューで習得・キャンセル・重複、900生成ガオン、工房素材検索）。ブラウザの工房APIは読込だけで、保存は行わない。
