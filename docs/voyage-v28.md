# 船旅と育て屋 v28

ビルド: `20260912-voyage-daycare-v28`

## 遊び方
- カラット・エンブレム取得後、カラットタウンのショップからスイスはかせが出てくる。仲間にして図鑑に登録したガオンが15種類以上なら「船のチケット」を受け取れる。足りない間は町を歩き、渡した後はネイチャータウンの研究施設へ戻る。
- カラット港・レスレ港の連絡船は毎日12:00以上17:00未満（日本時間）に乗船できる。チケットは消費しない。
- 乗船から実時間180秒で到着。到着後も船内を探索でき、デッキの添乗員に話しかけて下船する。再読み込みやアプリを閉じている間も到着時刻を維持する。
- デッキ・ラウンジ・客室の10人とは、それぞれ日本時間で1日1回対戦できる。勝敗にかかわらず対戦開始時にその日の権利を使う。負けた場合は船内の看護師が回復する。
- ラウンジのヤノケンに3回話すと対戦できる。コケゴロLv.22、アワミィLv.20、ヨルネコLv.24。勝利後は再戦しない。敗北時は再挑戦できる。
- レスレタウンの育て屋ではマリオに同種2匹を預ける。手持ち・ボックスから個体を選べる。健康な手持ちを1匹残す必要がある。
- 預けてから2000歩で同種Lv.1が生まれる。その種の通常レベル習得表にない技をランダムに1つ持つ。同タイプ・威力100以下を優先し、該当がなければ通常習得外の威力80以下から選ぶ。
- 子の個体と特別な技は預けた時に固定・保存する。親の個体・レベル・技は保持。受け取り時に親2匹と子1匹を返し、手持ち6匹を超える分はボックスへ送る。誕生前に引き取る場合は親だけを返し、進捗を取り消す。

## 互換性
v27で既に取得済みの「れんらくせんチケット」は新名称へ移行して維持する。新たな取得は博士の図鑑条件が必要。既存のセーブデータは初期化しない。育て屋に預けたガオンも、メロロン・ライメイの所持判定に含める。

## 素材
組み込み画像生成ツールを使用（CLI/APIフォールバックなし）。生成原本と実行用素材をリポジトリに保存。
- `assets/voyage-v28/source.png`: 船内家具・育て屋の生成シート
- `assets/voyage-v28/shipSeats.png`: 船内ソファ
- `assets/voyage-v28/shipHelm.png`: 操舵設備
- `assets/voyage-v28/daycareHouse.png`: 育て屋の建物
- `assets/voyage-v28/nurseryPen.png`: 屋内の飼育スペース

透明化を指定して生成し直した結果もRGBの市松背景だったため、実行用スプライトはCanvasで背景色を透過化し、各領域を切り出して最近傍で縮小した。原本は保持。`tools/prepareVoyageArt.cjs` に変換を記録。生成プロンプトは `docs/voyage-v28-prompts.json`。

## 検証
- 全36マップの出入口・NPC付近への到達性、ワープ先、登場種を検査。
- 14種類／15種類、博士の退店・研究施設への帰還、チケットの重複防止、旧チケットの移行。
- 日本時間の乗船境界、往復・再利用、180000msの到着境界、再読込後の期限保持。実時計でも180.161秒まで待機し、45秒後の再読み込みを挟んで到着を確認。
- 10人との実戦、同日再戦防止、翌日リセット、船内敗北時の回復、ヤノケン3回目の実戦。
- 全153種の特別な技候補、親の保持、再読込、1999歩／2000歩、実際の移動処理2000回、キャンセル、受取重複防止、ボックスへの移動。
- 既存の湖・発電所の試験、ライメイ・メロロンの時間条件、バトル画面、新規ゲーム開始を回帰検証。
- スマートフォン寸法の船内・育て屋・港表示。結果JSONとスクリーンショットは `artifacts/`（非公開・Git対象外）。
