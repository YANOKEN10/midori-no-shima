# 受付越しの会話・保存ショップ・針葉樹 v135

- 会話と公開時の通路検証で同じ受付判定を使用。カウンターの連続した範囲の向こう側にいる住人に、上下左右から会話可能。壁や商品棚越しには会話不可。
- 実行時レイアウトと保存時の編集用標準レイアウトが違うショップは、同梱の編集用標準データに対して指紋を含む通常の検証を行い、合格した編集のみ反映。指紋の無視は行わない。ラグの1マス間隔も適用。
- 山おくの外周の針葉樹を横2マスごとの単列に整理。入口を確保し、移動・削除・色変更などの手動編集を維持。

検証: verifyCounter135.cjs、verifyForestSpacing135.cjs、verifySavedShop135.cjs（公開済みデータをローカルで再現し、ショップのラグとworld.interactを確認）、verifyRug133.cjs、verifyForestBrowser132.cjs（mountain）。
