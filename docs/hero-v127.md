# 主人公の基本形と制作基準

男性：黒髪、水色のデニムジャケット、白いTシャツ、ネイビーのジーンズ、茶色のブーツ。
女性：茶髪、紺のノースリーブ、カーキのパンツ、濃色のブーツ。
マップとバトルはそれぞれユーザー指定の基本画像の頭身とフォルムを維持する。紫髪の旧制作案は不採用。

髪型は追加依頼を含めて男性7種類、女性6種類。男性はツーブロック、額を見せ前髪を立ち上げたソフトモヒカン、おしゃれ坊主を含む。女性はボブ、ツインテールを含む。
服は形を保った5色。顔・頭・体を貼り合わせない。歩行シートは組み込み image_gen で組み合わせごとに全身を個別生成し、65枚を用意した。
服の独立した50色の領域塗りは5種類の完成画像へ移行。髪色は元の色と50色を選べる。既存の持ち物は削除しない。

公開用は assets/hero-v127/map（32×48を4方向×3コマ）、battle（64×96）。元画像は同フォルダーの approved にローカル保持。
処理は全身コマの切り出し、同一シート内で共通倍率の最近傍縮小、透過端の整備。ツインテールは髪幅を含め最大32pxに収める。
髪の色変更は元の髪色に連続する領域へ適用し、服・肌・足元を保護する。バトルの服色も元の衣服パレットだけ変更する。
生成プロンプト・出力元は assets/hero-v127/prompts.json。組み込み画像生成を使用。

検証：verifyLayout127.cjs（320/375/430px）、verifyHero128.cjs（780歩行コマ・130バトル表示と髪色）、reviewMap127.cjs、reviewBattle127.cjs。
