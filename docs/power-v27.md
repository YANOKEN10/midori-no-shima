# カラットタウン・ラーデン発電所の章（v27）

本番: https://midori-no-shima.vercel.app/

## 遊べる範囲

マリンエンブレム取得 → 長い花の５番道路 → 花畑のカラットタウン。
北に６番道路・ラーデン発電所、東に７番道路・カラット港。乗船券取得後はレスレ港・８番道路・レスレタウンへ進める。港には病院とショップがあり、連絡船は往復可能。乗船券は消費しない。

## 試験

1. ジネル（ビリタマLv16、ビリボールLv18、コンセンLv26）に勝つと入口が開く。
2. 機械が並ぶ迷路の最奥の宝箱を開けると停電。床でも野生遭遇が起きる。
3. 宝箱近くの非常口から外へ出ると大雨・雷。目に見える試験のライメイLv20を倒すと復旧し、晴れる。
4. ジネルに報告するとカラット・エンブレムとれんらくせんチケットを一度だけ受け取る。

試験のライメイは捕獲不可。逃走・敗北では復旧せず再挑戦可能。捕獲用のライメイは試験後の週末に登場する。進行は段階ごとに端末へ保存し、ログイン中はクラウドにも保存する。

## 野生ガオン

- ６番道路: ジリジリ60%、ハネデン40%。
- 発電所内: プラグン49%、ビリタマ49%、ピリット1%、デンデマリ1%。これらは遭遇時の種類抽選割合。
- ライメイ: Lv20、捕獲率パラメーター3。日本時間で土日09:00以上13:00未満、および土曜17:00以上18:00未満。出現中は発電所の横に姿が見える。

週末のライメイと戦う際、戦闘前に次回日時を保存する。次回は現在の出現枠の開始から7日後（例: 土曜朝に倒すと翌土曜朝まで出ない。日曜朝なら翌日曜朝）。その週の別枠では再出現しない。手持ちまたはボックスにライメイがいる間は出現しない。逃がすと翌週以降の出現対象へ戻る。逃がした直後や同じ週には再出現しない。判定は端末のタイムゾーンに依存しない。

## 生成素材

Built-in image_genを使用。正確な最終プロンプト3本は [power-v27-prompts.json](power-v27-prompts.json) に保存。

保存先: `assets/power-v27/`

- 元画像: `power-source.png`、`flowers-source.png`、`machines-source.png`
- 建物・設備: `flowerHouse.png`、`powerStation.png`、`solarPanels.png`、`generator.png`
- 花・船: `flowersPink.png`、`flowersGold.png`、`flowerTree.png`、`ferry.png`
- 機械: `controlBank.png`、`transformers.png`、`pipePump.png`、`turbine.png`

透過を保持し、Canvasで切り出し・最近傍縮小。素材再抽出は `tools/preparePowerV27.cjs`。既存の海・桟橋・宝箱・ガオン画像も再利用。

試験とゲーム画面で同じ戦闘モジュールを共有するよう読み込みを統一。湖の試験を含め、開始時の後ろ姿・ガオンへの交代が通常の戦闘画面に表示される。

## 検証

- `tools/verifyPowerStoryV27.cjs [URL]`: 32マップの出入口と移動先、所長戦、宝箱、停電のセーブ再開、ライメイ戦、重複しない報酬、乗船制限、往復・到着セーブを検証。戦闘は実際の戦闘エンジンを使い、テスト用の選択入力と待ち時間短縮で実行。
- 同テストで米国ロサンゼルス設定のブラウザから日本時間の開始・終了時刻、土日・平日、翌週制限、手持ち・ボックス・逃がす操作、実際の捕獲を検証。
- `tools/verifyPowerBattleUiV27.cjs [URL]`: 実際の新規ゲーム開始操作の後、所長戦の主人公後ろ姿・ガオンへの交代・コマンド表示をスマートフォン画面で確認。
- `tools/verifyChapterStructure.cjs`: 全人物・出入口への到達性。
- `tools/verifyMarineStoryV26.cjs`: 従来の湖の試験とメロロンの再出現・捕獲の回帰確認。
- リリース確認: 新規開始から主人公の家を出るまで、32マップと素材の読み込み、ブラウザエラーなしを確認。
- `tools/verifyPowerVisualV27.cjs [URL]` と `tools/verifyPowerMobileV27.cjs [URL]`: 新規マップ全景とスマートフォンの花畑・設備・雷雨・停電・港を確認。画像は `artifacts/power-v27-*`。

既存のセーブ形式とガオンの能力値は変更しない。旧５番道路・カラットタウンのマップIDは保持する。
