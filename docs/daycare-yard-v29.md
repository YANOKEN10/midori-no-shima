# 育て屋の放牧表示

ビルド: `20260912-daycare-yard-v29`

レスレタウンの育て屋前に2つの柵付き放牧スペースを追加。預けている親2匹をセーブデータから直接読み、既存のガオン別歩行画像・表示サイズで歩かせる。手前の札に個体の名前（ニックネームがあれば優先）とレベルを表示する。

表示は会話不要。未預託時・引き取り後は表示しない。再読込後も預けた親が表示される。誕生待ちの子は表示せず、親のみを表示する。描画によって親・技・歩数・育て屋の進捗は変化しない。

確認: 全153種で柵内に収まる移動範囲、保存個体との一致、歩行変化、再読込、引き取り後の非表示、全36マップの通路・出入口、育て屋と船旅の回帰検証。スマートフォン画面で小型・大型ガオンを確認。新規画像生成は不要で、ゲーム内の既存ガオン画像と柵素材を使用。
