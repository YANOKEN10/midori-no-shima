# 草むらの接続とネイチャータウンのBGM

ビルド: `20260912-connected-grass-v30`

隣接する草むらの境目に既存の草画像を重ね、縦・横・4マスの交点をつなげる。草むらのないマスには描かず、外周や木・道の位置、通行・出現判定は変更しない。地面と足元の草は同じワールド座標で描く。山おく・田舎・水辺で既存の色と素材を継続使用。

ユーザー提供 `C:/Users/voraz/Downloads/Morning Meadow Path.wav` をMP3（160kbps、147.76秒、約2.96MB）に変換し、`assets/music-v30/morning-meadow-path.mp3` に保存。音の内容・長さは保持。ネイチャータウンと同町の室内でループ再生する。元のWAVは変更していない。町を出る・戦闘に入る際は停止し、既存の消音操作にも連動する。ブラウザで初回再生を保留された場合は次の音声再開操作で再試行する。

検証: 曲の実再生・長さ・ループ・消音・同曲の再呼出し・戦闘／道路への遷移、草の接続と草地外への非描画、地面と足元の描画一致、スマートフォンの山おく・1番道路・湖、新規ゲーム開始と本番リソース読込。
