# マップ工房・ゲーム内追加 v79

## マップ工房

- 初期配置の物・家具・建物に「しまう」「削除する」を追加。「しまった素材」から戻せます。削除は「戻す」で取り消せます。公開前に下書き保存・プレイ確認できます。
- 地面に描き込まれていた花、花壇、外周の木・壁・岩・柵を1マス単位で選択・移動・収納・削除できます。既存の複数マス素材は従来どおり配置物単位です。
- 建物を削除・収納すると入口も取り除きます。他マップからのカスタム接続が残る場合は、接続を解除してから公開してください。元からいる住人のイベント設定は引き続き維持します。
- スマホは「マップ」「素材を選ぶ」「選択・収納」の切り替え。1本指で選択・移動、2本指で拡大縮小・スクロールできます。2本指に切り替えた際は1本目の指による仮の変更を戻します。

## 人物・バトル・夜

- ヤノケンを画像生成で描き直し、32×48の歩行コマへ組み込み。頭だけを拡大する処理を廃止し、主人公と並べて比率を確認しました。
- ふくよかな大人、おばあさん、子供、おじいさんの4種類・48コマを画像生成。1番道路、ロッズタウン、2番道路、カラットタウンへトレーナーを追加。工房の「人」からも配置できます。
- トレーナー戦は相手の姿・名前・手持ち数を表示し、その後ガオンへ切り替えます。
- コケゴロのバトル表示を88から104へ拡大。つれ歩きのサイズは変更していません。
- 夜間の屋外を暗い青に寄せ、街灯や建物の明かりを表示。日本時間との連動は維持します。

## 採掘・土地・お店

- ショップで「つるはし」を500円で購入。岩に向かってAで採掘できます。1つの岩につき毎日5回、日本時間の日付変更で回復します。
- こいし・てっこうせき・どうこうせき・きんこうせき・ひかりのけっしょうの5種類。ショップの「うる」で売却できます。
- ショップの「土地・お店」で空き地のある町を選び、土地3000円・建築2000円で自分のお店を持てます。所有状態はプレイヤーのセーブに保存します。
- 建築したお店へ実際に入れます。奥のカウンターに向かってA、またはショップの「土地・お店」から商品陳列・売上受取・商品引き上げができます。
- ゲーム内の町のお客さんへの販売です。5分につき在庫から1個、通常のショップ買取額の1.5倍で売れます。ゲームを閉じている間も経過時間を計算し、売上は受け取り操作で加算します。在庫がなくなると止まります。
