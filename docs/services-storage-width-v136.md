# 共通室内・人物収納・外周幅 v136

添付された公開済み hospital / shop の配置を共通レイアウトの初期値として保持。家具、ラグ、既存受付の位置と会話機能を維持。各町で残っていたショップの色替えを停止し、町名をキーに人物の見た目と名前だけを変える。建物素材の港のショップも同じ配置。服屋・カット屋・プレイヤーの店は用途が異なるため対象外。

初回の旧編集データだけ serviceLayout136 マーカーで移行し、その後の編集・人物収納は保持する。標準データの指紋検証は引き続き必須。

後から追加した人・ガオンに「しまう」「戻す」と連続収納を対応。収納状態は保存され、描画と当たり判定・通路判定から除外。元からいる受付などの人物は収納不可。

山おくの北・南の入口脇を2マス幅の道にして、右側の木を16,18,…,28列に配置。幅30マス内で木が切れない。手動で移動・削除された木は維持。標準データ49マップの木を検査して、他の横はみ出しはなかった。

検証: verifyServices136.cjs、verifyStorePerson136.cjs（実際の編集画面の収納・復元・保存）、verifyServiceBrowser136.cjs（2町の病院・ショップ描画）、verifyRug133.cjs、verifyCounter135.cjs、verifyWorld131.cjs。
