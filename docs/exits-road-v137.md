# 出入口2マスと道の連続表示 v137

山おくの上下の出口を14・15列の2マスとし、どちらも同じ移動先・到着位置・イベント条件を使用。編集用出入口枠も2マスとして表示。

追加側の地面は山おくの元の道と同じ描画にする。森林地面のクリア後に床変更を適用し、道が草地へ戻る順序不具合も修正。

屋外で道につながる境界の出入口は、表示用の地面を隣接する道にそろえ、マップ端にも道の切れ目や縁取りを入れない。室内と移動先の設定は変更しない。

検証: verifyExits137.cjs（2マス、枠、移動条件、地面、234境界マス）、verifyExitBrowser137.cjs（山おくと1番道路の上端・下端の実描画）、verifyServices136.cjs、verifyWorld131.cjs。
