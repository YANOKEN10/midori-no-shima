# マップ工房（管理者画面）

URL: /map-editor/

既存の管理者アカウント「ヤノケン」でログインします。ゲームと同じ「あいことば」を使用します。新しい管理者アカウントやパスワードは作成していません。

## 使い方

1. 左上で編集する町・道路・洞窟・室内を選びます。
2. 「人」「ガオン」「庭の植物」「木・建物」「室内家具」「地面・床」から素材を選び、マップをクリックして配置します。
3. 「選択・移動」で配置物をドラッグできます。右側の X / Y や、選択中の矢印キーでも移動できます。人・ガオンは初期位置、向き、行動を設定できます。
4. ペットは「その場にいる」「自由に歩く」「飼い主について歩く」を選択できます。ついて歩く場合は、同じマップの人を飼い主に指定します。追加した住人には名前と会話も設定できます。
5. 室内では家具の配置と移動、床の塗り替え、ラグの位置・幅・高さを変更できます。「ラグをなくす」も使えます。
6. 「下書き保存」は管理者用の保存です。「プレイ確認」で実際のゲーム表示を確認できます。プレビューでは冒険のセーブを書き換えません。
7. 「公開する」の確認画面で確定すると、全プレイヤーの次回の読み込みから反映されます。「前の公開状態に戻す」で直前の公開状態に戻せます。

既存の住人の会話・クエスト・戦闘と、建物の出入口は維持します。既存の住人と出入口つき建物は削除できませんが、移動できます。新しく配置した住人やガオン、家具などは削除できます。

人は30種類、ガオンは156種類、庭の植物は12種類、既存の屋外素材は63種類、室内家具は17種類です。追加する人は会話用の住人です。新規の対戦トレーナーの手持ち設定はこの画面では扱いません。

ショップとガオン病院は既存ゲームと同じ共通室内を編集します。新しく置いた家は「追加した家（共通室内）」を使います。v75以降は「入口・接続」で既存の別室内や屋外への行き先も指定できます。

## 技術・検証

- /api/map-editor は署名つきゲームログインと実際のユーザーレコードを確認。既存のアカウントIDと作成日時に管理権限を固定し、表示名やクライアントの権限フラグを信用しません。
- 既存の非公開ドキュメントストアを使用。下書きと公開データを分離し、バージョン比較と原子的書き込みで競合を拒否。公開読み取りは公開済みデータだけを返します。
- クライアントとサーバーが同じ検証器を使います。素材の許可リスト、位置・件数・文字数、元マップ指紋、入口への到達、住人同士の重なり、住人や入口をふさぐ配置を確認します。任意スクリプトや外部画像URLは受け付けません。
- 標準マップは公開せずに維持。編集状態は管理者が公開を確定した場合だけ保存されます。
- tools/verifyMapEditorV72.cjs はメモリ内のテスト用ストアとローカルHTTPサーバーで実行。本番のアカウント・下書き・公開マップは書き換えません。
- 検証範囲: 全87マップの初期状態、権限拒否、下書き分離、競合、衝突、建物のドアと家具の移動、公開・ロールバック、パレットからの人とガオンの配置、飼い主指定、実ゲーム読み込み、プレビューのセーブ保護、スマホ幅、ブラウザー例外なし。

元マップや種族を変更した開発時は tools/buildMapEditorCatalogV72.cjs で素材の基準データを更新してください。元データの指紋が異なる古い下書きは、自動適用せず再確認を求めます。

生成した植物12種類は assets/garden-v72 に保存。大きな木3×3、針葉樹2×3、広葉樹2×2、小さい木1×2、1マスの木1×1、鉢植え・プランター・刈り込みの植木・モンステラ・アジサイを含みます。元画像から背景透過を保って切り出し、屋外と室内の両方に配置できます。画像生成は組み込みの image_gen を使用しました。生成指示は assets/garden-v72/prompt.md に記録しています。

## 追加素材 v73

- 草むら: 春夏秋冬 × 短い・ふつう・長い、12種類。1マスで歩ける草むらとして配置。元マップの出現テーブルがある場所では遭遇対象です。
- 花畑: 20色。地面の模様を残し、通行できます。
- 岩: 灰・白・茶・黄土・赤・黒、各1マスの石と2×2マスの大岩、12種類。配置範囲は通行不可です。
- 道: 草原・レンガ・土・砂・タイル・舗装道路・ヨーロッパの石畳・スイスの山村・サヘルの土の道、9種類。床ブラシで塗れます。
- 既存素材: 各マップの地面・水・壁の見た目、既存の木・建物・装飾、室内ごとの家具をパレットへ追加。素材検索でマップ名でも探せます。
- 新しい画像53点は assets/nature-v73 に保存。組み込み image_gen で個別生成し、色重ねではなく独立した画像を使用。指示は同フォルダーの prompts.md に保存。

## 道・庭・高台・入口 v75

組み込み image_gen で54点を個別生成しました。草道・けもの道は中央、ふち、外角、内角、丸い部分、飾りを用意し、回転した方向違いを含め33種類の「貼る道タイル」から1マスずつ塗れます。透過部分は下の草地が見えます。青い装飾タイル、和風の丸石畳、白レンガも含みます。

「庭の小物」にはベンチ、花のカート、柵、街灯、看板、巣箱、置物、切り株、草花、プランター、レンガ壁、通り抜けられる門、城壁、お城など29種類を追加しました。「地面・床」には白・青の雪、金色・白い砂、灰色・クリームのコンクリートを追加しました。お城は6×6マスで、初期設定では追加した家の共通室内へ入れます。

### 高さを変える

「高さ・昇降」で元の高さ／1段／2段を選び、マスを塗ります。1段差の境目で、画面上で下側にあるマスへはしご・階段・坂を置くと、そのマスと1マス上を行き来できます。横から崖を越えたり、2段を一度に登ったりはできません。高台への通路がないと公開できません。室内の高さ変更は対象外です。

### 門やドアをつなぐ

1. 門・建物を選択し「この門・ドアの接続を設定」を押します。任意の通路マスは「入口・接続」から指定できます。
2. 移動先のマップと、その入口のX／Yを選びます。
3. 「戻る位置」「到着位置」を入口から上下左右の1マスで指定します。室内の下端にある出口なら、到着位置を1マス上にします。
4. 「往復できる」を選ぶと、接続先の入口も自動でつながります。「片道」も選べます。
5. 下書き保存、プレイ確認、公開の順で確かめます。接続先には公開済みの配置を使い、下書き中の別マップは使いません。壁・家具・人に重なる到着位置、別の入口と重なる到着位置、イベント条件付き入口の上書きは拒否します。

単に通り抜ける門には接続設定は不要です。門の左右の柱は通れず、中央は歩けます。新しいマップ自体の作成はこの機能には含みません。接続後に門や建物を移動したときは入口座標も合わせて調整してください。
