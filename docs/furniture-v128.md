# 家具・机上配置 v128

32pxのマスに合わせた粗いドット絵。画像生成は組み込み image_gen、各素材を個別生成。
公開画像：assets/furniture-v128/*.png。生成記録：同フォルダーの prompts.json。原寸 source はローカル保持。
本棚2種とキッチンは既存の配置サイズを保ち、余白を詰めた画像へ更新する。
長机（縦・横）、円机、四角い机、机（縦・横）の6形状×明るい木・こげ茶・白木・青の4色を追加。
観葉植物4種類と花瓶2種類を追加。

パソコン・レジは机の範囲内に収まる配置で重なりを許可。道具同士・机同士や他の家具同士の重なりは許可しない。
保存データは従来の家具座標形式を保ち、読み込み時に支持する机を判定。机を先に描画し、机上の道具を12px上げて最後に描く。
通常の床置きも維持する。机を削除した場合は道具が床置きへ戻る。
この判定はマップ工房のプレビューとゲーム、サーバーの検証で共通。
