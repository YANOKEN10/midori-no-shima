# 持ち物117種類（193）

参照: https://gamewith.jp/pokemon-sv/article/show/375985 （2026-09-27確認）。重複掲載を除く117種類をすべて別名にした。対応一覧は tools/fixtures/heldItems193.json。公開データには新しい名前のみ。

ユーザーの回答により、他作品固有のタイプ・対象は既存の8タイプ・ガオンへ置換。専用の姿変更は対象ガオンの覚醒状態（能力補正と覚醒マーク）として実装。体重は既存HP基礎値から決定する既定体重、軽量道具で半減。原動・共鳴の性質を該当する2系統に設定し、むし系統の棘肌との接触防護も実装。

天候・場・防護幕・拘束・技制限・性質交換・ため技・体重技の計22技を追加し、そのわざじゅもんも登録（計314）。場の持続と消費アイテムは戦闘単位で処理。通常バトルでは使用済みの持ち物がなくなり、オンライン対戦は専用コピー上で消費。ショップ品ぞろえは工房で選択。拾えるアイテムと人物の贈り物にも117種類を追加。

実装: heldCore193.js はブラウザとCommonJSサーバーで共有。サーバーが .js→.mjs をrequireしない構成を保持。わざじゅもん一覧も自己完結したmjs。モデル読み込みはAPIのtry内で必要時に行う。

検証: verifyHeld193.cjs（登録117、独自名、発動境界・倍率・消費・持続・専用対象・サーバーバトル）、verifyBattle193.cjs（実ブラウザ通常バトルでHP1耐久・消費・終了後の戦闘状態掃除）、verifyMoves192.cjs（300種のルール、変化技と基礎能力の保持、314巻物）。
