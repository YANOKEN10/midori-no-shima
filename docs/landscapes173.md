# 地形・室内の再設計 v173

洞窟、火山、遺跡、ヨウガン山、家・施設・客室、クリアタウン周辺、吹雪の山道、氷河を再構成。公開定義を含め32マップ。ベレリオ・リーフ・ラーデン・7番道路のメリレの谷を含む5マップには、水際の立体的な岸を追加。

## 素材

76種類。洞窟・火山・遺跡14、室内9、雪と氷12、岸12、四方向の崖24、滝の部品5。工房の「新しい地形素材」6分類から配置可能。「山の壁」にも新しい崖を収録。既存の legacy73-cliff は変更していない。崖は草・砂・雪・氷・火山岩・遺跡の6種類、各上下左右1×1マス。

新素材は16×16論理ドットを32×32へ整数倍表示。PNG書き出しは assets/terrain-v173/tiles/。生成した地面を減色・縮小し、壁・崖・橋・階段・室内床は既存のCanvas素材方式で描画。描画検査で76素材すべての2×2画素ブロック一致を確認。

## データ維持

新レイアウトは layout173 フラグによる一度だけの移行。古い装飾は工房の収納に保持。NPCの識別子、会話、イベント、既存出口を保持。拾えるアイテムは保持。火山のマグマは水扱いせず通行不可。新地形は工房で変更して保存できる。

## 検証

- node tools/verifyLayout173.mjs：31マップ、全出口・人物への到達、移行の冪等性、マグマの当たり判定、旧崖と24新崖の登録。
- node tools/verifyTerrain173.cjs：76素材のドット尺度、工房6分類、実ブラウザー描画、PNG書き出し。
- node tools/verifyMaps173.cjs：36マップの画像と配置検査。
- artifacts/maps173/index.html：制作プレビュー。

この更新はローカル実装。前回の200素材は本番公開済み、ZIPは200/PKヘッダーを確認済み。

滝は既存の配置・大きさ・向きを引き継いで1×1タイルへ分解。メリレの2本の滝は261マスの独立した素材へ変換し、工房で1マスごとに編集可能。一体の滝素材は配置一覧から外し、既存分は収納に保持。水流は4フレームでアニメーションする。

地面・壁・崖・岸・橋・階段・滝はいずれも1×1タイルで構成。家・木・家具のみ必要な複数マスを使用。プレビュー画像は確認用で、ゲーム内の背景画像としては使用しない。
