## 画像と生成記録
組み込み image_gen を使用。画像はプロジェクトに保存済み。
- 連れ歩き: `assets/followers-v14/NNN.png`（320×160の8コマ）と `assets/followers-v14/NNN/{down,up,right,left}-{a,b}.png`（各80×80）。
- 今回変更した14種類の対戦・図鑑画像: `assets/monsters/redesign-v14/front/` と `back/`。
- 道具25種類: `assets/items-v13/`。
- 人物30種類: `assets/people-v13/`（既存の8種類＋生成した22種類）。
- プロンプト: `docs/followers-v14-prompts.json`、`docs/followers-v14-retries.json`、`docs/item-v13-prompts.json`、`docs/npc-v13-prompts.json`。
- 読み込み用のコマ分割・透過マット除去・サイズ統一はCanvasで処理。歩行アニメーションは生成した実画像のみを使用。
