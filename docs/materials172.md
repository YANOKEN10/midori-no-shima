# ガオンワールド 追加素材200（v172）

マップ素材160種類と持ち物アイテム40種類。10分類に20種類ずつ登録。

- マップ工房の「追加素材200」で分類を選び、素材をクリックして配置。
- 鉱石・収穫アイテムは拾えるアイテムとして配置され、マップではキラキラ表示。
- 鉱石は換金用、収穫物はHP回復用。ショップの商品編集にも登録済み。
- 一覧は /materials/ 。検索・背景切替・個別PNG・一括ZIP保存に対応。
- 1マス32px、描画の基準ドットは2px。背景透過。大きな素材はマス単位の寸法。

制作: Codex内蔵 image_gen を素材ごとに使用。添付8枚は題材・構成の参考。
生成原本は保持し、最近傍リサイズと減色でゲーム用PNGへ整形。
全素材の寸法と分類: assets/materials-v172/manifest.json
生成元とプロンプト: tools/materialSources172.json
整形スクリプト: tools/prepareMaterials172.cjs

検証: tools/verifyMaterials172.mjs（登録数・配置・回転・移動・通行判定・アイテム・英語）、tools/verifyMaterials172.cjs（画像寸法・一覧・マップ工房）。
