## レア出現

新規ゲーム時に種ごとに到達可能な1マスをランダム選択し、seedと座標をセーブ。既存セーブは読み込み時に一度だけ付与して端末へ保存する。クラウド保存にも同じ座標が含まれる。
森の3人のトレーナーに勝ち、図鑑を受け取った後に森南側から生息地へ進める。
通常エンカウントとは別に、そのマスに入ったとき直接抽選。普通の出現率を掛け合わせない。

|ガオン|生息地|出現率|レベル|種族値合計|
|---|---|---|---|---|
|コケゴロ|森の聖域|1%|32〜36|610|
|オバケシ|忘れられた遺跡|3%|34〜38|520|
|ムラサキビ|忘れられた遺跡|1%|40〜45|610|
|ヨウガンヌシ|火山の奥|1%|45〜50|650|
|ヤミノヌシ|深闇の洞窟|1%|50〜55|670|

上記5種類を通常抽選から除外。ユウレイン・ボウレイも通常抽選から除外し進化限定。
図鑑の「種族値・育成」に生息地・出現率・進化限定の説明を掲載。セーブ固有の座標は公開しない。

- verifyRareWorld.cjs: 実際の歩行後処理から5種類のレア戦闘選択、マップ表示、コケゴロ戦闘表示。
- verifyGaonV11.cjs: 全306画像読込、今回58画像の80px・二値透過・余白、進化・検索・前後姿一覧。
- verifyTraining.cjs / verifyRelease.cjs / verifyCatalog.cjs: 個体値・努力値・旧セーブ、通常開始、スマートフォンと公開図鑑153件。
