# v80 素材採取・マップ工房

- 採掘セット（500円）をショップで購入。旧つるはしは読み込み時に自動移行します。
- 屋外の目印付き「素材木」「採掘岩」に向かって A を押すと採取できます。草むらや目印のない木・岩は対象外です。
- 木材・樹脂・硬い木材、石・鉱石を入手し、ショップで売却または自分の店に出品できます。各採取場所で日本時間の1日5回まで。
- 既存の木・岩から、近づける場所を種類ごとに最大3か所指定。マップ工房で配置を変えた場合は公開後の配置から選び直します。
- マップ上のマウスホイール上で拡大、下で縮小（10～400%）。カーソル位置を中心に拡縮。素材欄では通常スクロールです。
- 素材カテゴリを4群に整理。各ボタンの文字は横書き1行表示です。
- 元からいる住人・トレーナーも、選択欄の「名前」から表示名を変更できます。下書き保存・公開に対応。内部識別名、会話、イベント、手持ちは維持します。

検証: tools/verifyResourcesV80.cjs（ローカルのテスト用アカウントとメモリストア。実際の公開データは変更しません）。
