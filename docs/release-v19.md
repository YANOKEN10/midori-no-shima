# v19 森の外周とバトル画面

- 木・奥の森・バトル背景／下部枠・男女の主人公の後ろ姿をbuilt-in image_genで新規生成。
- 元画像とゲーム用画像はassets/world-v19、プロンプトはdocs/world-v19-prompts.json。
- 森の外周は横・縦・角とも新しい素材で描画。旧外周の木を重ねず、後列の森と手前の木を合成。出口と当たり判定は維持。
- バトル開始時は主人公の後ろ姿。呼び出し後、主人公が退いてガオンが登場。男女と選択した髪・服の色に対応。
- ガオンは128から88ドットに縮小。名前・レベル・HP欄は小型化し、下部に紺色／金色の操作欄を配置。経験値は非表示。
- 画像読込中の旧タイトル・旧バトル背景・旧ガオン画像へのフォールバックを削除。

検証：実画面の縦横・角、360人物フレーム、図鑑153種類、出口29マス、スマホ起動と退出、主人公登場、技選択、長い名前、レベルアップ。遅延読込でも旧画面が表示されないことを検証。
