# v139 霊・シンボルエンカウント・出現率・キラキラ・縦柵

- 工房の「霊」に女の子、おじいさん、白い服の長髪の霊を追加。マップは32×48、バトルは64×96の人間と同じ枠。女の子は2マス以内で280msかけて消え、4マス離れると戻る。「霊の動き」で変更でき、トレーナー設定時は消えない。
- 「シンボルガオン」から配置し、最低・最高レベルを設定。接触で捕獲可能な野生バトル。戦闘後は消え、マップに入り直すと再出現する。
- 出現設定に1歩ごとの出現率0～100%と、各ガオンの割合を追加。合計100%になるよう他の割合を調整。時間帯などの条件により出現対象が限られる場合は、対象内で再配分される。
- 既存・追加アイテムともマップ上は同一のキラキラ。素材選択と編集欄では内容を確認でき、ゲームでは拾ってから内容がわかる。
- 縦の木柵を32×32の透明素材へ置換。柱の太さ8ピクセル。旧素材キーも新素材を描画し、縦に長い配置は繰り返し描画する。

## 検証

- tools/verifyGhostSymbols139.cjs：消失・復帰、シンボル配置・収納・多重起動防止・失敗時復旧、1～30種の割合調整、0%設定。
- tools/verifyBrowser139.cjs：工房で3種の霊、トレーナー化、シンボルとレベル、出現率を編集して保存。実際の接触から野生バトル・捕獲まで確認。API保存はモックし、公開マップの内容は変更しない。
- tools/verifyPickups138.cjs / tools/verifyPeople138.cjs：拾得・収納・人物名・報酬の回帰検証。
- artifacts/ghosts139-review.png：既存人物と霊の大きさ、バトル画像、キラキラ、縦横の柵の表示を比較。
