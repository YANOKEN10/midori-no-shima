# 種族値・個体値・努力値

全153種類が HP・こうげき・ぼうぎょ・とくこう・とくぼう・すばやさ の6能力を持ちます。

- 種族値: 種類ごとに固定。既存の5能力を維持し、とくぼうは従来のまほうと同じ値を初期設定。
- 個体値: 各能力0〜31。生成時に決まり、捕獲・進化・保存で変化しません。
- 努力値: 初期値0。各能力252、合計510まで。相手を倒したとき、その場で戦っている生存中のガオンに相手の種類固有の1〜3ポイントを付与。レベル100でも獲得可能。逃走・捕獲では付与しません。
- 通常能力: floor((2×種族値 + 個体値 + floor(努力値/4))×レベル/100)+5。
- HP: 同じ式の末尾を +レベル+10 にします。性格補正は今回の対象外です。

敵種別の努力値は最も高い種族値の能力に固定。同率なら図鑑番号で決定します。進化前1、中間2、進化後3、単独種2、伝説3ポイントです。

以前の0〜15の個体値は2倍に変換し、旧計算式での強さを保ちます。旧まほう個体値をとくこう・とくぼうへ引き継ぎ、過去の努力値は記録がないので0から始めます。手持ちとボックスの全員を一度だけ移行し、HP・技・持ち物・ストーリー・進化は維持します。

ゲームの「つよさ」で左右を押すと、種族値・個体値・努力値の詳細を表示。公開図鑑の各「種族値・育成」に種族値と倒したときの努力値を表示します。

検証: tools/verifyTraining.cjs。153種の値、計算式、上限、HP増加、ひんし時、レベル100、旧データ移行と再読み込み、進化保持、実バトルでの獲得、画面表示を確認します。
