# 序盤の制作・検証

## 実装

- ネイチャータウン、主人公の家、研究施設、山おく、1ばんどうろ、ロッズタウン、村の家、2ばんどうろ、ネイチャーのもり、共通の病院、共通のショップの計11マップ。
- 女の子の目撃談→山おくのラテット逃走→スイスはかせからラグネット15個→ロッズタウンでヤノケンから図鑑。贈り物は各1回。
- 2ばんどうろ6人、森3人。最初のトレーナー対戦は2ばんどうろ。先へ進む接続には会話・受取の進行条件を設定。
- 両タウンに外観共通の病院・ショップ。病院はHP/状態/技回数を全回復、薬・ラグネットを購入可能。
- 通常・スーパー・ハイパー・マスターの4種類。マスターは野生相手に捕獲成功確定。旧アイテム名は読み込み時に新名称へ移行。
- 木2×3マス全体が通行不可。ドア・階段・はしごは幅1マス。川岸も通行不可で橋は通行可能。草むらが主人公の足元を隠す。
- 草むらと川のシンプルなバトル背景を描画できる。今回の野生戦は草むら・山・森で、川バトルを開始する移動システムは今回の範囲に含まない。
- 旧マップデータは mapsLegacyV4.js に保存。ガオン・人物・旧マップ素材は削除していない。
- 旧セーブは仲間・所持品を保ち、序盤の家へ移す。新しいシナリオのフラグは旧ストーリーと独立。

## 検証

- verifyChapterStructure.cjs：全11マップの入口・NPCへの到達、出現種の実在、6人/3人の人数。
- verifyChapterFlow.cjs：ストーリー順序、贈り物一度、捕獲、図鑑、病院の実移動と回復、購入、9人全員との対戦、マスター捕獲。ブラウザJSエラー0。
- verifyChapterMobile.cjs：タッチスティック移動、ドア、川岸、木の占有域、草むら、タウン無遭遇。ブラウザJSエラー0。
- 対戦網羅テストには高レベルのテスト仲間、捕獲テストには固定乱数を使用。テスト専用ブラウザ内だけの変更で、ゲームの通常データや本番乱数は変更していない。実機iPhoneと長期的な難易度調整は未検証。
