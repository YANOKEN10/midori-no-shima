# VORAZ MONSTERS 〜ガオンと ギャラクシー・タウン〜

ゲームボーイカラー風の ガオン収集RPGです。ブラウザで URL を開くだけで遊べます。
**Claude を通さずに、アプリへ直接ログインできます。**

- なまえ＋あいことば だけで はじめられます（メールアドレスは なくてOK）
- メールアドレスを 登録しておけば、メールでも ログインできます
- ログインしていれば、**パソコンでも スマホでも おなじ つづき**から遊べます

**あそぶ → <https://midori-no-shima.vercel.app/>**

スマホは「ホーム画面に追加」すると、アプリのように 全画面で あそべます。

---

## ものがたり

山の中の こやで うまれた しょうねん **レオ**。
山を おりた ことは 一ども ない。

- **やまの むら** … ぞくちょうに よばれ、「ガオン」という とくいせいぶつの はなしを 聞く
- **ラグ・ネット** … のびちぢみする あみ。よわった ガオンを つかまえられる
- **やまみち** … たかい くさから ガオンが とびだす。さいしょの 1ぴきは 自分で つかまえる
- **やまの おくち** … でんせつの ガオン **ラテット** と であう。ラテットは 走り去り、
  あとには **リーフ・コンパス** が のこされていた
- ぞくちょうに みとめられ、レオは 山を おりる

そこからは **8つの タウン** を めぐる たび。
さいごは せかいの ちゅうしん **ギャラクシー・タウン** の
**ガオンバトル大会** で ゆうしょうを めざします。

### タウンと すすみかた

| じゅん | タウン | できること |
|---|---|---|
| 1 | **ハーバー・タウン** | ライバル **フィロア** と であう／みなとエンブレム |
| 2 | **サンド・タウン** | すなエンブレム |
| 3 | **フォレスト・タウン** | もりエンブレム（この あたりで フィロアと 2かいめ） |
| 4 | **ストーン・タウン** | いしエンブレム |
| 5 | **アクア・タウン** | みずうみエンブレム／でんせつの **メロロン** |
| 6 | **スカイ・タウン** | そらエンブレム／でんせつの **ディーナ** |
| 7 | **フレイム・タウン** | ほのおエンブレム（この あたりで フィロアと 3かいめ） |
| 8 | **ギャラクシー・タウン** | エンブレム 7つで **たいかいパス**。かいじょうで 4連戦 |

大会は 1かいせん → 2かいせん → じゅんけっしょう → **けっしょう：フィロア**。
ゆうしょうすると、やまの おくちに ふたたび **ラテット** が あらわれます。

### ライバル フィロア

うみを わたって きた 青い かみの しょうねん。あかるくて まっすぐ。
「ギャラクシー・タウンの 大会で ゆうしょうする」のが ゆめ。
たびの あいだに 3かい、そして 大会の けっしょうで たたかいます。

## ガオン

- ぜんぶで **153しゅるい**（でんせつ 3ひきを ふくむ／すべて オリジナル）
- つよさは **たいりょく・こうげき・ぼうぎょ・まほう・すばやさ** の 5つ
- タイプは 8つ： ノーマル／くさ／ほのお／みず／でんき／じめん／むし／やみ
- レベルが あがると わざを おぼえ、しんかします（しんかライン 45組）
- ドット絵は **32×32ドット**。28の からだつき に みみ・つの・つばさ・しっぽ・
  目・口・もようを くみあわせ、タイプごと＋かぞくごとの 色（24色セット）で ぬっています

### でんせつの ガオン

| なまえ | すがた | とくちょう |
|---|---|---|
| **ラテット** | 金の たてがみの ライオン | この せかいで さいきょう。やまの ぬし |
| **ディーナ** | にじいろの クジャク | すばやさが とびぬけている |
| **メロロン** | きょだいな アザラシ | たいりょくが とても たかい |

## そうさ

| | パソコン | スマホ |
|---|---|---|
| うごく | ←↑↓→ / WASD | 画面下の 十字キー |
| けってい・はなす | Z / Enter / スペース | A |
| もどる・キャンセル | X / Esc / BackSpace | B |
| メニュー | E | START |

ゲームパッドでも あそべます。

### がめんの いろ

メニュー →「せってい」→「がめんの いろ」で
`カラー（さいしょ）` / `ゲームボーイ みどり` / `ゲームボーイ グレー` に かえられます。

## アカウントと きろく

| えらびかた | いること | できること |
|---|---|---|
| **この たんまつだけ** | なにも いらない | その きかいの中だけに きろくが のこる |
| **なまえ＋あいことば** | なまえと あいことば | どの きかいでも つづきが できる |
| **メールアドレスも 登録** | ＋メールアドレス | なまえを わすれても メールで ログインできる |

- ログインは **なまえでも メールアドレスでも** できます
- あるくたび・たたかいのあとに その きかいへ 自動ほぞん、ログイン中は クラウドにも
- メニューの「レポート」で いつでも 手動ほぞん

## つくり

```
index.html         画面のわく（ログイン画面も ここ）
src/
  main.js          タイトル → ログイン → ぼうけん の ながれ
  world.js         フィールドと ものがたりの イベント
  battle.js        たたかい（てもち 0ひきでも ネットは なげられる）
  menu.js          メニュー（ガオン・どうぐ・ずかん・せってい）
  ui.js            メッセージわく と えらぶ画面
  gfx.js           えがきかたと いろセット（320x288＝ゲームボーイの2倍）
  tiles.js         マスの え
  data/
    monsprite.js   32x32の ドット絵を パーツから 組み立てる しくみ
    species*.js    153ひきの ガオン
    maps.js        やま・8タウン・7つの みち・大会かいじょう
api/               とうろく／ログイン／クラウド保存
```

- 画像ファイルは 1つも つかっていません。**ドット絵は すべて コードの中**にあります
