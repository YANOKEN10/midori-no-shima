# ガオン・ワールド 〜七つの谷と リーフ・コンパス〜

スイス・アルプスを思わせる山岳地方を舞台に、153種の「ガオン」と暮らす完全オリジナルのRPGです。戦闘の読み合いはモンスター育成RPGを参考にしつつ、地理・建築・人物・物語は、湖、氷河、針葉樹林、石垣の牧道、木造シャレー、登山鉄道から成る独自世界へ作り直しています。

## ものがたり

主人公は、深いモミの森に囲まれた「風鳴り谷」の小さな丸太小屋で暮らしています。ある朝、谷を絶えず吹いていた風が突然止まり、野生のガオンたちが一斉に雪山を見上げます。谷守オルドは、これは七つの谷を結ぶ「山の息づかい」が乱れた兆しだと語ります。

主人公が受け取るのは、ガオンを傷つけずに保護・調査するための「ラグ・ネット」と、観察記録を残す図鑑です。山道で出会う小さなガオン「ラテッテ」から「リーフ・コンパス」を託され、湖岸、棚田、モミの森、峡谷、入江、雪稜、高原を巡ります。コンパスの矢印は次の目的地を示し、STARTメニューからいつでも消せます。

各地の守り手は、その土地の暮らしと自然を守っています。問題を解き、対話とバトルを経て七つのエンブレムを集めるたび、ラグ・ネットはガオンとの信頼を読み取れるようになり、捕獲性能が15%ずつ上がります。

旅の途中で出会うフィロアは、勝ち負けだけを追うライバルではありません。途絶えた古道を地図に戻そうとする若い測量士です。主人公と競い、ときには協力しながら、七つの谷から「星環の都」へ続く忘れられた道を明らかにします。

最後の舞台は、星環の都で開かれる山岳祭。七人の守り手と住民、そしてガオンたちの前で、主人公は各地で学んだ関わり方を示します。優勝そのものではなく、失われた風の理由を知り、七つの谷を再び結ぶことが旅の結末です。

| 1 | アーレ湖港 | 湖守ナギ／湖風エンブレム |

| 3 | モミ響きの森 | 薬草守シノ／森響エンブレム |
| 4 | 石笛の峡谷 | 石工守ゴウ／石笛エンブレム |
| 5 | 水鏡の入江 | 水路守ミナ／水鏡エンブレム |
| 6 | 白嶺のシャレー | 雪稜守ソラ／雪翼エンブレム |
| 7 | 夕映え高原 | 星見守カグラ／夕映エンブレム |

## 操作

- 移動: 矢印キー / WASD / 画面の方向ボタン
- 決定・調べる: Z / Enter / Aボタン
- 戻る: X / Esc / Bボタン
- START: E / STARTボタン
- リーフ・コンパス: START → どうぐ → リーフ・コンパス

## ビジュアル方針

マップ、建物、木、橋、崖、湖、列車、室内家具は、ガオンと人物のスプライト密度に合わせた高密度ドット素材で構成しています。低解像度の平坦な色面ではなく、木目、石積み、積雪、草花、水面、影を段階的に描き分けています。
