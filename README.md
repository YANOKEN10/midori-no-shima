# VORAZ MONSTERS 〜みどりのしまの ものがたり〜

ゲームボーイ風の モンスター収集RPGです。ブラウザで URL を開くだけで遊べます。
**Claude を通さずに、アプリへ直接ログインできます。**

- なまえ＋あいことば だけで はじめられます（メールアドレスは なくてOK）
- メールアドレスを 登録しておけば、メールでも ログインできます
- ログインしていれば、**パソコンでも スマホでも おなじ つづき**から遊べます

**あそぶ → <https://midori-no-shima.vercel.app/>**

スマホは「ホーム画面に追加」すると、アプリのように 全画面で あそべます。

---

## あそびかた

たかい くさに はいると やせいの モンスターが とびだしてきます。
たたかって よわらせ、ボールを なげて つかまえましょう。
ジムリーダーを たおして バッジを あつめ、やまの ちょうじょうを めざします。

### すすみかた

1. **はじまりの村** … 家を出て、きたの けんきゅうじょへ
2. **けんきゅうじょ** … ハカセから 3びきの なかから 1ぴきを もらう
3. **1ばんどうろ** … たかい くさで つかまえる／トレーナーと しょうぶ
4. **みなとまち** … センターで かいふく、ショップで かいもの、**みなとジム**（みず）
5. **2ばんどうろ → ひかりの ほらあな**
6. **ひのやまタウン** … **かざんジム**（ほのお）
7. **やまの ちょうじょう** … ライバルとの さいごの しょうぶ

### そうさ

| | パソコン | スマホ |
|---|---|---|
| うごく | ←↑↓→ / WASD | 画面下の 十字キー |
| けってい・はなす | Z / Enter / スペース | A |
| もどる・キャンセル | X / Esc / BackSpace | B |
| メニュー | E | START |

ゲームパッドでも あそべます。

### がめんの いろ

ゲームボーイカラー（金銀）くらいの **カラー表示**が さいしょから えらばれています。
メニュー →「せってい」→「がめんの いろ」で つぎの 3つに かえられます。

| | |
|---|---|
| **カラー**（さいしょ） | くさは みどり、うみは あお、やねは あか…と ものごとに 色が つきます |
| ゲームボーイ みどり | むかしの ゲームボーイと おなじ 4だんかいの みどり |
| ゲームボーイ グレー | 4だんかいの しろくろ |

しくみは 本物の ゲームボーイカラーと おなじで、え は 4だんかいの こさで かき、
「くさ」「みず」「ほのお」などの **いろセット**を ものごとに あてはめています。
モンスターは タイプの 色（くさ＝みどり／ほのお＝あか／でんき＝きいろ…）で ぬられます。

### モンスター

- ぜんぶで **23しゅるい**（すべて このゲームの オリジナルです）
- レベルが あがると わざを おぼえ、しんかします
- タイプは 8つ： ノーマル／くさ／ほのお／みず／でんき／じめん／むし／やみ
- じょうたい： どく／やけど／まひ／ねむり

## アカウントと きろく

### 3つの はじめかた

| えらびかた | いること | できること |
|---|---|---|
| **この たんまつだけ** | なにも いらない | その きかいの中だけに きろくが のこる |
| **なまえ＋あいことば** | なまえと あいことば | どの きかいでも つづきが できる |
| **メールアドレスも 登録** | ＋メールアドレス | なまえを わすれても メールで ログインできる |

- ログインは **なまえでも メールアドレスでも** できます（どちらか片方でOK）
- あとから「せってい → アカウント」で メールアドレスを 足すことも できます
- **あいことばを わすれると、あずけた きろくは とりだせません**（メールを登録しておくと、なまえを思い出せなくても入れます）

### きろくの ながれ

- あるくたび・たたかいのあとに、**その きかいの中**へ 自動で ほぞん
- ログインしていれば、しょうぶや かいふくの あとに **クラウドへも** あずけます
- メニューの「レポート」で、いつでも 手動で あずけられます
- べつの きかいで あたらしい きろくが あるときは、どちらを つかうか たずねます

## つくり

```
index.html         画面のわく（ログイン画面も ここ）
src/
  main.js          タイトル → ログイン → ぼうけん の ながれ
  world.js         フィールド（あるく・はなす・イベント）
  battle.js        たたかい
  menu.js          メニュー（てもち・どうぐ・ずかん・せってい）
  ui.js            メッセージわく と えらぶ画面
  gfx.js           えがきかたと いろセット（320x288＝ゲームボーイの2倍）
  tiles.js         マスの え
  input.js         キーボード・タッチ・ゲームパッド
  audio.js         しかくい波の おと
  cloud.js         ログインと クラウド保存の やりとり
  save.js          きろくの よみかき
  gate.js          ログイン画面（HTML）
  data/            モンスター・わざ・どうぐ・マップ・ドット絵
api/
  auth.js          とうろく と ログイン
  save.js          きろくの あずけ・とりだし
  account.js       メール登録・あいことば変更・たいかい
  _lib.js/_store.js  共通しょり（Vercel Blob / 手元では .devdata/）
```

- 画像ファイルは 1つも つかっていません。**ドット絵は すべて コードの中**にあります
- 文字は Google Fonts の DotGothic16（読みこめないときは 端末のゴシック体）

## 手元で うごかす

```bash
node serve.js
```

<http://localhost:5179> をひらいてください。
手元では アカウントの きろくが `.devdata/` フォルダに たまります（Vercel Blob のかわり）。

## 安全のはなし

| | |
|---|---|
| あいことば | そのままでは 保存しません。1人ごとの乱数を混ぜて `scrypt` でハッシュ化 |
| 照合 | 時間差から中身が漏れない比べかた（timingSafeEqual） |
| まちがえたとき | わざと すこし待たせて 総当たりを おそくする |
| ログイン状態 | HMAC-SHA256 で署名した券。1年で切れる |
| きろく | 非公開の Blob に 1人1ファイル。ファイル名も 推測できないハッシュ |
| メールアドレス | 画面には `hi***@example.com` のように かくして出す |
| 呼び出せる場所 | 公開URLと localhost だけ（CORS） |
| きろくの大きさ | 1人 300KB まで |
