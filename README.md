# ガオン・ワールド

ネイチャータウンから出発し、ガオンを仲間にして図鑑を完成させる、スイスの自然と村をイメージしたドットRPGです。

正式ストーリーは [docs/story-canonical.md](docs/story-canonical.md)。今回制作した序盤と検証結果は [docs/chapter-one-release.md](docs/chapter-one-release.md) を参照してください。

## 今回遊べる範囲

村の女の子の目撃談を聞き、山おくでラテットに出会います。村へ戻ってスイスはかせに報告すると、ラグネットを15個もらえます。1ばんどうろからロッズタウンへ進み、ヤノケンから図鑑を受け取ったら、2ばんどうろとネイチャーのもりを探索できます。

両タウンにガオンびょういんとショップがあります。弱ったガオンの回復や、薬・ラグネットの購入ができます。

## 操作

矢印/WASDまたは画面のスティックで移動。Z/Enter/Aで会話・決定。X/Esc/Bで戻る。E/STARTでメニュー。

## 起動

`node serve.js` または `Start-Game.ps1`。ローカルURLは http://127.0.0.1:5179/ 。ビルド処理はありません。作業フォルダは I:\2026\Claude code\gaon-world。

今後の町やストーリーは、ユーザーの続きを基に制作します。
