# Mountain cliff tiles v118

Generated with the built-in image_gen tool, then nearest-neighbor resized to 32x32 pixels (one map square). No existing assets replaced.

Prompt set: One edge-to-edge opaque chunky 32x32 logical pixel top-down RPG mountain cliff tile, warm brown rock, tan facets, ochre dirt lip, heavy dark creases, no fine detail, text, grass or scenery. Horizontal: dirt lip across top, repeat left/right. Left side: dirt lip at right, repeat top/bottom. Right side: dirt lip at left, repeat top/bottom. Lower left and right corners: raised dirt in top inner corner joining the matching side and horizontal front. Each side and corner generated separately, using horizontal tile as style/palette reference.

Files: cliff118-h.png, cliff118-left.png, cliff118-right.png, cliff118-corner-left.png, cliff118-corner-right.png.

In the map workshop choose 山の壁. Place pieces in adjacent squares. All are solid walls, support ordinary save/publish, rotations and per-object material colors. These are visual/collision pieces; use the existing 高さ・昇降 controls when adding an elevated playable area.
