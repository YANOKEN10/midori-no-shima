# 人物素材 v119

歩行シート141枚（4方向×3コマ、1コマ32×48）、バトル画像84枚（64×96）。背景透過、描画時は補間なし。主人公は男女の正面・背面を個別収録。

バトル体型はユーザー指定の赤いニット帽の人物を基準とし、子供と太った人は個性を維持。主人公は男性がデニムジャケットとジーンズ・茶色の編み上げ靴、女性が紺のノースリーブとカーキパンツ・黒い編み上げブーツ。

50種類は冬服男女・吟遊詩人・探検家・花屋それぞれ基本色を含む10配色。別途女性10髪型差分。歩行用の服装・髪型選択に対応。バトルの主人公は基本衣装の前後画像を使用し、歩行用の全カスタム髪型・衣装の組み合わせ画像とは別。

新規バトル全84枚を目視確認。旧生成の捕獲球があった画像は再生成して差し替え済み。
